# Screenshots

This folder contains screenshots and screen recordings used in the README and project documentation.

## Suggested captures

| File | Description |
|---|---|
| `hero.gif` | ~15 s screen recording: tilt left stick → Warthog moves across grass world with coordinate HUD |
| `sidebar.png` | Sidebar expanded, showing all toggles and camera sliders |
| `overview.png` | Full-window view of the scene (skybox + grass + vehicle) |
| `social-preview.png` | 1280×640 Open Graph card for GitHub social preview |

## Recording tips

- Use [LICEcap](https://www.cockos.com/licecap/) (Windows/macOS) or [Peek](https://github.com/phw/peek) (Linux) to capture GIFs.
- Keep GIFs under 5 MB; aim for 480 p at 15 fps.
- For `social-preview.png` use a dark scene angle so the vehicle and skybox are both visible.
